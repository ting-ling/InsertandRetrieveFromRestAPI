# InsertandRetrieveFromRestAPI
Create a local database via SSMS 2022, Create RestAPI for inserting and retrieving data from Fronted via C# connecting to the local database. Creating a simple local website to insert and retrieve data. This project is related a normal user signup account and login account. 

##First Version MYRESTAPI project
1. Two simple APIs had create for SignUp and Login
2. Inserting into DB when SignUp
3. Retrieving from DB when Login
4. Setup connection String to DB

##First Version FirstWedsite project
1. Create a simple to button for the user to signup and login
2. Once signup, data will be insert into DB
3. Login will be success and prompt simple message "Login Success"

##First Version DB project 
1.Create a simple Database with a table named as tblLogin
2. Storing userID,username,createdDateTime,email,phoneNo,password
